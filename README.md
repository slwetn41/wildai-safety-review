## WildAI是什么？和WildCard（野卡）是什么关系

WildCard这个名字，老用户不陌生。它2022年前后起步，主打海外虚拟信用卡：用户注册、充值之后开一张虚拟卡，自己去绑ChatGPT Plus、Claude、Midjourney、Netflix这些海外服务。放在当时，这几乎是国内用户订阅海外AI工具最顺的一条路——注册门槛低，支付方便，一度是中文用户圈里名气最大的虚拟卡平台。当然代价也有：开卡费$11.99，充值手续费约3.5%，在同类平台里不算便宜。
